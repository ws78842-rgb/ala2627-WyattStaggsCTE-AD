# Diamond Pulse Baseball

## Run it

In a terminal, run:

```sh
python game/game.py
```

## Batting

- The CPU pitcher throws every five seconds. Watch the `o` travel from pitcher `P` to batter `B`.
- Tap **Space** or **S** while the ball is in flight to swing.
- Swing while the ball is inside the marked **HIT ZONE** to get a hit.
- Swing too early or too late and it is a swing and a miss.
- Let a pitch pass to take it. Four balls earns a walk; three strikes is an out.
- Press **Q** during a pitch to quit. The game ends after three outs.

Perfectly timed hits are home runs. Try to score as many runs as you can before making three outs.
